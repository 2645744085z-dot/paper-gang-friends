# 纸牌帮·群友专属版

给群友使用的中文联机版协作扑克劫案：3–6 位玩家通过筹码表达牌力判断，不直接讨论手牌，一起打开三只保险箱。公网部署后，把房间链接和房间码发到群里即可。

## 玩法规则

1. 每次劫案分 **翻牌前 → 翻牌 → 转牌 → 河牌** 四个阶段，每人发 2 张底牌，公共牌逐阶段翻开。
2. 每个阶段，每位玩家从公共池拿一枚筹码（1★~N★），也可以**抢走别人面前的筹码**——被抢的人立刻重新选择。
3. 换拿新筹码会自动归还你手里的旧筹码；玩家数 = 筹码星级上限。
4. 河牌阶段全员选定后，由房主公开牌型结算：**终局筹码从小到大必须与牌力从弱到强完全一致** → 打开一只保险箱；否则触发一次警报。
5. 先开满 **3 只保险箱**（全员胜利）或触发 **3 次警报**（行动失败）时终局。

## 本地启动

```bash
npm install
npm run dev        # 开发模式，默认 http://127.0.0.1:3000
```

生产模式：

```bash
npm run build      # tsc 编译到 dist/
npm start          # 运行 dist/server.js
```

端口与监听地址可用 `.env` 风格环境变量覆盖（参考 `.env.example`）：

- `PORT`（默认 3000）
- `HOST`（默认 127.0.0.1，局域网联机可设 `0.0.0.0`）

## 自动化测试

```bash
npm test           # vitest：牌型评估 + 房间流程（抢筹/阶段/结算/终局）
```

当前测试结果：5 个测试文件、28 个断言全部通过。覆盖 7 张牌取最佳 5 张、皇家同花顺、A2345 低顺、筹码抢夺与换筹、房主推进阶段、警报/保险箱循环，以及 Socket.IO 创建/加入房间。

## 联机说明

- 房主创建房间后把 **六位房间码** 或邀请链接发给朋友，浏览器即玩，无需注册。
- 断线 90 秒内重新打开页面会自动回到原座位（浏览器本地保存会话标识）。
- 对局进行中不能中途加入新玩家；房主可在开局前移除误入的玩家。

## 实时事件

服务端是唯一状态源，动作经校验后广播：`room:state`、`room:player-joined`、`room:player-left`、`game:phase`、`chip:action`、`chip:returned`、`chip:stolen`、`game:result`、`room:error`。每个动作带有唯一编号、服务器时间、阶段、行动者、来源、受影响玩家和双方统计；前端按动作编号去重，并在右侧固定面板显示当前阶段/全局记录。

## 目录结构

- `src/server.ts`：Express 静态服务与 Socket.IO 房间协议。
- `src/game.ts`：房间状态、筹码校验、阶段推进、保险箱结算。
- `src/poker.ts`：标准德州扑克 7 张牌最佳 5 张评估器。
- `index.html`、`app.js`、`styles.css`：无大型前端框架的中文响应式界面。

## MVP 边界

房间状态暂存在内存，服务重启后清空；挑战卡、专家卡、持久化存储、正式公网部署和账号体系留给后续增强。浏览器多窗口测试时请使用不同浏览器配置或无痕窗口，避免浏览器本地会话标识被共享。
